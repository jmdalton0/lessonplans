Area of Operation II.H

Objective

  • The learner will understand the navigation systems and radar services and how and when to use them.
  • The learner will develop skills to use these systems and services for flight.
  • The learner will mitigate risk by understanding and adjusting for errors and limitations of these systems.

VOR

Very High Frequency Omnidirectional Range

Use

  • reference and variable signals
  • to from flag
  • each tick is 2 degrees of deviation

Limitations

  • line of sight
  • cone of confusion
  • reverse sensing
  • signal integrity - morse code id

Service Volumes

AIM 1-1-8

Types

  • VOR
  • VORDME
  • VORTAC

Checks

  • VOT - 180 to, 360 from (±4)
  • Ground Checkpoints (±4)
  • Airborne Checkpoints (±6)
  • Dual VOR Check (±4)

DME

Distance Measuring Equipment

Use

  • interrogation and reply signals

Limitations

  • line of sight
  • slant range distance (1nm per 1000 agl)

Service Volumes

AIM 1-1-8

GPS

Global Positioning System

Segments

  • space - satellites
  • control - master control, 5 monitoring stations, 3 ground antennas
  • user - receiver

Limitations

  • line of sight
  • expired database

RAIM - Receiver Autonomous Integrity Monitoring

  • verify signal coverage along route of flight
  • alert is fault is detected
  • requires at least 5 satellites in view

WAAS

Wide Area Augmentation System

Augmented GPS

  • can be used for precision approaches
  • geo-stationary satellite

LAAS (GBAS)

  • uses ground based components at the airport

Radar Services

  • flight following
  • safety alerts
  • traffic advisories

Transponder

Mode A

  • 4 digit code
  • position

Mode C

  • altitude

Mode S

  • more info
  • required for TCAS and ADSB

ADSB

Automatic Dependent Surveillance Broadcast

  • broadcast GPS location, altitude, ground speed
  • out / in
  • required in A, in and above B and C, above 10,000 excluding 2,500 agl
